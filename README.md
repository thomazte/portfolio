# Portfólio — Thomaz Arthur (zamoht.exe)

Portfólio pessoal de desenvolvedor: página única em HTML, CSS e JavaScript puro, com animações em GSAP. Publicado em https://zamoht.vercel.app.

## Rodar

Sirva a pasta localmente e abra http://localhost:5500:

```bash
python3 -m http.server 5500
```

## Testar

O CI confere a sintaxe dos scripts. Para rodar a mesma verificação localmente:

```bash
for f in js/*.js; do node --check "$f"; done
```
